# Support

Thanks for using this project. This file explains where to get help and what information to include.

## Where to ask questions

Start with the project's README and docs folder. For questions that the
documentation does not answer, email <jscraik@brainwav.io> and include the
repository name and what you are trying to do.

This shared support route does not require access to a private tracker or a
GitHub Discussions area.

## Where to report bugs

Use the repository's **Bug report** issue form when Issues are enabled. A
repository may provide its own intake route in its README or support file.
If that route is unavailable to you, email <jscraik@brainwav.io>.

Please include:

- Version/commit SHA
- Steps to reproduce (minimal)
- Expected vs actual behavior
- Logs and environment details

## Feature requests

Use the repository's **Feature request** issue form or its documented intake
route. Email <jscraik@brainwav.io> if you cannot access that route.

## Security issues

Report vulnerabilities privately using the repository's security policy or the
[shared security policy](https://github.com/jscraik/.github/blob/main/SECURITY.md).
Do not include vulnerability details in a public issue.

## Response expectations

This is an open source project. Support is best-effort and response times vary.
